# Intake — Daedalus 1.0

- **Requester:** Carls (personal project, also used for work and client projects)
- **Problem:** AI-assisted development is spread across terminals, chats and tools.
  There is no single place that enforces the standard workflow, keeps AI usage low
  and checks every change before it merges.
- **Users:** one developer on one PC (Windows; WSL for work).
- **Must-haves:** projects hub with import, Work/Client/Personal profiles, project
  chat (intake → spec interview → mock → plan), pipeline board, task runner with
  worktrees, live agent consoles, cross-model review, providers over ACP, usage and
  quota fallback, inbox, Obsidian-style docs (wikilinks, backlinks, graph, embeds,
  quick switcher).
- **Out of scope for 1.0:** multiple users, hosting online, deploying to servers,
  mobile app, replacing the editor.
- **Constraints:** local only (127.0.0.1), TypeScript stack, no stored API keys,
  Gemini off for work unless company policy allows it.
